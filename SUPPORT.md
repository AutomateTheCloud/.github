# Getting help

Automate the Cloud is a small nonprofit run by volunteers. We answer as time allows, and we
can't promise a response time.

## Using our code

- **Something is broken:** open a bug report in that repository's **Issues** tab. Include the
  version you're using and the smallest configuration that shows the problem.
- **A question about how something works:** start with the repository's README and examples,
  then open a question in its **Issues** tab if they don't answer it.
- **A security problem:** do not open an issue. Follow the repository's security policy.

## Technology help for nonprofits

We provide free and below-cost IT help to nonprofits, schools, congregations, and community groups
that serve the public. That help is not handled through GitHub: see
[automatethe.cloud](https://automatethe.cloud) or email **info@automatethe.cloud**.

## Anything else

Email **info@automatethe.cloud**.
